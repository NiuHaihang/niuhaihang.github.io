# 普通话音色试听

沿用英语应用的 edge-tts 预生成 MP3 方式。A（晓晓）已选定并接入识字页，B 保留供比较。

- A：`zh-CN-XiaoxiaoNeural.mp3`（晓晓）
- B：`zh-CN-XiaoyiNeural.mp3`（晓伊）
- 两种音色均以 `-15%` 语速合成，未调整音高。
- 剪去服务在每段前后附带的静音，词语与例句之间留 650 毫秒，各组之间留 1.1 秒；句内停顿保持合成结果。
- 每段依次朗读：天空／天空蓝蓝的；耳朵／兔子的耳朵长长的；月亮／月亮挂在夜空中。
- 生成工具和参数见 `manifest.json`。工具说明：https://github.com/rany2/edge-tts

试听通过后再确定整库的音色和语速。多音字的整库音频仍需按学习项核对读音。
