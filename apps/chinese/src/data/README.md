## 数据约定

`textbooks.json` 每册保留教材字表的阅读顺序。每条为 `[汉字, 拼音, 辅助词语, 原创例句]`；无原创例句时末项为空，不摘录课文补齐。界面的每 6 项是短练习分组，与教材课次无一一对应关系。

识字表拼音依据教材标注，保留本音和轻声的区别。六年级写字表没有附拼音，拼音按辅助词语的读音补充。辅助词语用于认读，不宣称是教材词语表；姓氏、地名、人物名和古汉语读音按相应词语呈现。朗读使用预生成的晓晓普通话录音，播放词语，避免先单独朗读多音字时读成另一读音。

2026-11-04 接入录音时，修正三处辅助组词与目标读音不一致的问题：鲜（xiǎn）改为“鲜有”，单（chán）改为“单于”，落（là）改为“丢三落四”。读音参考[汉典“鲜”](https://www.zdic.net/hans/鲜)、[教育部《国语辞典》“单于”](https://dict.concised.moe.edu.tw/dictView.jsp?ID=31917&la=0&powerMode=0)和[汉典“丢三落四”](https://www.zdic.net/hans/丢三落四)。教材字形、拼音及顺序保持原有核对结果。

候选辅助词语参考 jieba 0.42.1 的 MIT 词典，经筛选、人工调整；拼音整理使用 pypinyin 0.55.0，并针对教材读音校正。它们仅用于本次数据整理，不是网站运行依赖。许可证见 [THIRD_PARTY_LICENSES.txt](../../public/THIRD_PARTY_LICENSES.txt)。教材仅作为字表核对依据，仓库不分发教材页面、插图或课文。

维护时应同时核对字形、拼音、顺序、新字数和蓝色读音数，更新来源日期及回归测试中的数量和修订内容。不能只以总项数相等作为校对完成的证据。
