# 小兔语文

面向小学一到六年级，按人教社现行电子教材的上下册字表学习认字，部署地址为 `/chinese/`。

- 十二册共 3,460 个分册、分读音学习项；一至五年级采用识字表，六年级采用写字表。各册字数、核对日期和来源见 [字库说明](src/data/README.md)。
- 每次最多 6 个学习项，每页 12 组。先看大字、拼音、辅助词语和已有的原创例句，再完成听词选字和组词选字；末组按实际字数出题。
- 年级、上下册、课程星星、练过的字、练习天数和错字保存在本机 `bunny-chinese.v1` 中，与其他科目独立。
- 错字复习每次最多 6 个读音。同一个读音的两种题型都答对后，才移出错字小口袋，其他读音继续保留。
- 原精选主题的星级与新分组无法对应，因此不迁移主题星级；保留原来练过的字和错字。旧错字没有记录读音，迁移时采用该字首次出现的读音。

朗读使用预生成的晓晓普通话音频（`zh-CN-XiaoxiaoNeural`），语速 `-15%`，与选定的 A 试听一致。词语与例句分开录制，间隔 650 毫秒；切换汉字、返回首页或重新点击时停止旧录音。音频无法加载时提示重试，也可看拼音继续。首页可以关闭朗读，改用拼音选字。

共 2,916 段录音（去重后的词语和例句），保存在 `public/audio/readings/`，生成参数与文本清单见 `public/audio/manifest.json`。音频随网站静态部署，无需在浏览器连接合成服务。

进入一个汉字时，只预取当前词语和已有例句的完整音频；切字或退出时取消未完成的预取。关闭朗读时不预取。首页及 PWA 安装不会下载整个音频库。在生产构建中，Service Worker 按需缓存这些录音，并支持音频分段请求；最多缓存 600 段、保存一年，浏览器也可能因空间不足清除缓存。已缓存的录音可以离线重复播放，未缓存的内容仍需联网。录音内容或音色改变时须更新 `vite.config.ts` 中的音频缓存版本。

重新生成需要 Python 环境中的 `edge-tts` 和 PATH 中的 `ffmpeg`：

```bash
python scripts/gen-audio.py
```

脚本按 32 个句子批量合成，严格核对服务返回的句子文本与时间标记，再分别切出录音。它会跳过已经完成的录音，外部服务失败会明确报错，可重新运行续传。音色或语速改变时需重新生成对应文件。发音来自语音合成，多音字的实际读音仍需在教学使用时核对。

沿用英语应用的基础样式、小兔、随机数和评分规则，仅添加识字界面所需的样式。

```bash
pnpm dev:chinese  # http://127.0.0.1:5175
pnpm --filter @bunny/chinese test
pnpm build:site   # 与数学、英语一起构建，可通过科目菜单互相切换
```
