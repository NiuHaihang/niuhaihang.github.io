# 小兔古诗词

独立入口 `/poetry/`，与数学、英语、语文并列。纯前端，不需要账号或在线语音服务。

## 内容范围与来源

- 目录依据教育部《[义务教育语文课程标准（2022年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582344386456.pdf)》附录1，一至六年级的 75 篇推荐篇目，保留目录序号。
- 另收录辛弃疾《清平乐·村居》《西江月·夜行黄沙道中》，共 77 篇。《清平乐·村居》的原文也可参见[维基文库公版文本](https://zh.wikisource.org/zh-hans/清平樂_(辛棄疾))。
- 原文为古代公版作品；诗意是本项目面向儿童编写的简述，不复制现代译文、教材注解或插图。
- 《古朗月行》仅选开头四句，标题明确标注节选；《赋得古原草送别》收录八句。重名诗通过首句区分。
- **年级是本项目按难度建议的学习分组，不是人教版教材册次。** 各级数量为 10 / 13 / 12 / 13 / 16 / 13。首页也可选择全部诗词。
- 学习包含原文、按字拼音、整首/逐句朗读、简明诗意、隐藏原文逐句提示；闯关包含诗意选择、补字、接句和整首排序。闯关星星不代表口头背诵已被自动评测。

## 拼音与音频

`src/data/poems-source.txt` 保存原文与原创诗意，`scripts/gen-content.py` 使用 pypinyin 0.55.0 生成静态 JSON，并对古诗语境中的多音字校正。网站运行不下载拼音库。许可证见 `public/THIRD_PARTY_LICENSES.txt`。

拼音中的“一、不”统一显示本调，朗读使用自然变调；保留现代词语中的轻声。校对示例：

- “见牛羊”“忽见”读 xiàn；“供耕织”读 gòng；“亡赖”读 wú；“剥莲蓬”读 bāo。
- “鬓毛衰”按现代普通话读 shuāi，“石径斜”读 xié，“轻骑”读 qí。参考[新华社采访北京大学中文系孙玉文教授](https://app.xinhuanet.com/news/article.html?articleId=20260904ade18682f96048bca0360a4df77f6f99)。
- “供耕织”参考[学校公开的人教版教材页面](https://lywgyxx.szftedu.cn/xkjc/yw/202209/U020220910607776914733.pdf)；“见”的古义参考[汉典](https://zdic.net/hans/见)。
- “返景”中的“景”采用人教社教师教学用书的 jǐng，解释为日光；参见[人民教育出版社的字词辨析](https://k.sina.cn/article_2173867535_8192960f01901ey6u.html)。

`scripts/gen-audio.py` 使用已选定的 `zh-CN-XiaoxiaoNeural`，语速 `-15%`。每首一次合成，用明确的句末停顿分隔诗句；验证返回的句界文本后切分逐句文件。易误读的通假字在合成请求中使用同音替代，不改变显示原文。生成过程只向语音服务发送公版诗句，不含儿童数据。

```bash
python scripts/gen-content.py  # 需要 pypinyin==0.55.0
python scripts/gen-audio.py    # 需要 edge-tts==7.3.1 和 ffmpeg
```

共有 417 个 MP3，约 18.57 MiB，包含 77 个整首录音和 340 个逐句片段。所有文件经过解码完整性检查；合成音频仍可按实际试听结果继续校正读音与节奏。

音频不加入 service-worker 全量预缓存。只有打开诗词后才完整预取当前整首和当前选中句；切换诗句时按需下载新的片段。CacheFirst 保留最多 300 个完整录音，支持 Range 请求；网络失败会明确提示重试。单播放器避免两个录音重叠，离开页面或关闭声音后停止播放。

## 进度与验证

`bunny-poetry.v1` 单独保存建议年级、声音开关及每首的最高星数，不读写识字记录。只在完整闯关结束后记星，中途离开不记录。

```bash
pnpm dev:poetry
pnpm --filter @bunny/poetry test
pnpm build:site
```

测试覆盖 75 篇目录完整性、同名与节选、多音字、每字拼音、全量音频、闯关唯一正确答案、排序和最高星进度恢复。`build:site` 同时生成四个应用，GitHub Pages 的仓库子路径由 `VITE_BASE` 支持。
